Paste the whole Forecast List
  1. In Word, Ctrl+A to select the whole document, then copy it.
  2. Click the box on the left and paste — every aircraft, every section, in one go. Pasting again refreshes each aircraft's rows.
Or paste a Flying report (Excel)
  1. In Excel, select the report's cells and copy them, then paste in the same box.
  2. This is detected automatically and updates TTAF, last flight date, and cycle references on the print — separately from the Forecast List above.
